# MacroSnap 🥗

## Quick Start (Run with 1 Click / Command)

Simply double-click **`run.bat`** or run in Command Prompt / Terminal:
```cmd
.\run.bat
```

Or in PowerShell:
```powershell
.\run.ps1
```

---

### Manual Setup
If you prefer running step-by-step:
```powershell
pip install -r .\requirements.txt
.\venv\Scripts\Activate.ps1
streamlit run app.py
```
